# bootstrap

## Purpose
Framework bootstrap. `app.php` wires routing, middleware and the JSON error contract; `providers.php` registers service providers. `cache/` holds Laravel-generated files — never edit them by hand.

## Key Files
| File | Description |
|------|-------------|
| `app.php` | `Application::configure()`: routes (web/api/console + health `/up`), middleware stack, exception rendering |
| `providers.php` | Provider list — `AppServiceProvider` only |
| `cache/.gitignore` | Ignores everything in `cache/` except itself |
| `cache/packages.php` | Generated package discovery manifest (`package:discover`) |
| `cache/services.php` | Generated provider manifest + deferred-service map |

## Subdirectories
| Directory | Purpose |
|-----------|---------|
| `cache/` | Generated manifests. Committed by Laravel, rebuilt on `package:discover` — do not hand-edit |

## For AI Agents

### Working In This Directory
- Middleware wiring in `app.php` is the source of truth for the API contract, not per-route code:
  - `statefulApi()` — Sanctum cookie auth for the SPA origins.
  - `validateCsrfTokens(except: ['api/v1/webhooks/*'])` — gateway webhooks bypass CSRF.
  - `append(HandleCors::class)` and `alias(['perm' => RequirePermission::class])` — `perm:<slug>` on admin routes resolves to `App\Http\Middleware\RequirePermission`.
  - `appendToGroup('api', ForceJson::class)` — every `/api/*` request is forced to JSON.
- Exception renderers produce the standard body `{error:{code,message}}`: `AuthenticationException` → 401 `UNAUTHENTICATED`, `AuthorizationException` → 403 `FORBIDDEN`, `NotFoundHttpException` → 404 `NOT_FOUND`. Messages are Vietnamese literals.
- `shouldRenderJsonWhen` covers `api/*` plus `expectsJson()`; anything outside `api/*` keeps the default HTML error pages.
- Add new middleware aliases here, not in a controller.
- `bootstrap/cache/*` is regenerated by `package:discover` and config caching — do not commit hand edits.

### Testing Requirements
- Middleware changes must keep `RbacTest` green (401 unauthenticated, 403 wrong permission, 200 with permission).

### Common Patterns
- Routing is declared in `routes/*.php`; `bootstrap/app.php` only points at those files and configures cross-cutting behaviour.

## Dependencies

### Internal
- `routes/web.php`, `routes/api.php`, `routes/console.php` — registered via `withRouting()`.
- `App\Http\Middleware\ForceJson` and `App\Http\Middleware\RequirePermission` — aliased here.

### External
- `laravel/framework:13`, `laravel/sanctum:4` middleware.
